# Run 1801：连续时间更新与三任务共包控制

## 实验条件与原始记录

- 两块 HackRF 独立接收，均以 4 Msps 录制 80 s；板端 200 ms 周期、300 个计划时隙，`rf_mode=same_channel_diagnostic`。
- 板端完整逐槽记录见 [board.board.log](board.board.log)；联合匹配见 [plan.report.md](analyses/plan_match/plan.report.md) 及同目录 CSV/JSON。原始 IQ 和两侧逐包 JSONL 保存在各自的 `captures/` 目录，本地 IQ 不纳入 Git。
- 计划由 291 个纯时间更新时隙和 9 个命令发送时隙组成。命令 43、44、45 各重复 3 次，计 3 个逻辑任务。

## 结果

| 指标 | 结果 | 口径 |
|---|---:|---|
| 板端完成 | 300/300 | `reached=generated=primary_completed=tx_completed=300`；`deadline_miss=dma_timeout=0` |
| BLE / IEEE 有效解码 | 300/300 / 300/300 | 两侧独立解码，按 Run ID 与时隙去重；BLE 的 300 个 primary 不计入任务尝试 |
| 同一次发送双方有效 | 300/300 | 两侧共享控制与时间字段逐槽一致；四象限为双方 300、仅 BLE 0、仅 IEEE 0、双方均无 0 |
| 命令发送尝试双方有效 | 9/9 | 命令 43、44、45 各 3/3 |
| 联合有效解析任务 | 3/3 | 每个命令两侧均恢复了本侧目标、操作码与参数；重发不增加任务分母 |
| 实时软件处理任务 | 0/3 | 两侧均未提供已校准的外部参考误差界，各侧 9 次命令接收均因 `time_quality_insufficient` 被拒绝 |

接收摘要显示两侧均处理 320,000,000 个样本、完整写入 640,000,000 字节 IQ，程序正常结束，队列溢出为 0，高水位为 2。HackRF 日志未报告 USB shortfall。对各侧 299 个相邻时隙，按标称 200 ms 检查 IQ 包起点间隔，BLE 和 IEEE 的最大绝对偏差分别为 0.7345 ms 和 0.73425 ms，均无超过 1 ms 的间隔。这是时间轴诊断，不是两台接收机之间的同步精度或独立的 USB 无丢样证明。

板端 `secondary_dma_late_avg_us=80429`、`secondary_dma_late_max_us=80861`。这些是相对于板端计划 secondary 起点的 DMA 统计，实际 RF 发射起点仍未测量；不能把它们直接当作固定传播/处理延迟校正。

## 假设参考界的离线功能回放

将每侧自身的逐包流分别以 **1 ms 假设参考误差界**回放，BLE 与 IEEE 各自接受并软件处理命令 43、44、45 各一次，另外 6 个重复发送在各侧被去重。BLE 最终软件状态为 2，记录 `TRIGGER(9)`；IEEE 最终软件状态为 3，记录 `TRIGGER(7)`。逐侧结果见 [BLE 回放](analyses/assumed_1ms/ble/control.summary.json) 和 [IEEE 回放](analyses/assumed_1ms/zigbee/control.summary.json)。

1 ms 是人为输入的功能测试条件，**不是**本轮测得的板端 RF 参考误差上界。回放中的 `software_processed` 是本地 IQ 样本域的模拟软件动作，不能解释为实时处理、物理执行或两设备同步执行。两台 HackRF 的采集零点和时钟未校准，不能相减其样本索引计算跨机执行时差。

另用相同两份逐包记录完成[立即处理软件基线](analyses/immediate_baseline/report.md)，并从两份原始 IQ 独立重新解调复核：两侧各接受并软件处理 3/3 项任务，各去重 6 个命令包；重新解调的 300 条本侧记录与采集时结果逐槽、逐采样位置一致。该基线不使用时间模型或假设界，也不在线评估截止时间；它验证即时处理功能，不测同步精度。

## 结论与后续

本轮充分支持当前 SDR 原型在同频诊断条件下，以连续单个 secondary 序列同时传递时间更新和三项不同控制任务，且两条独立接收链均能完整恢复、关联、去重。它尚不能证明实际同步执行精度、标准跨信道 AuxPtr 跟随、商用设备兼容或相对分别发送的收益。

下一步应按相同三任务、截止时间和重复次数实现分别发送基线与同包立即处理基线；若要评估同步精度，需要独立校准两台采集起点、采样率和固定延迟，并测量板端实际空口参考点与执行事件。
