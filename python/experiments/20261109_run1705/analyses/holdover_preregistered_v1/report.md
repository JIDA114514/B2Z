# Run 1705：独立双接收时间保持复核

按 [预先固定的时间保持方案](../../../../../doc/independent_sync_holdover_experiment_plan.md)分析两份独立 4 Msps IQ；板端完整日志记录 300/300 个计划时隙均完成 secondary DMA，`deadline_miss=dma_timeout=0`。BLE 与 IEEE 接收链各解出 300/300 个时间更新，168 个固定验证槽均为双侧有效。两侧各处理完整 80 s IQ，接收队列未溢出。

| 不同包训练、离线观察掩码 | 绝对相对估计差中位数 | P95 | 最大值 |
|---|---:|---:|---:|
| 2 点训练后冻结 | 23.291 ms | 44.087 ms | 46.251 ms |
| 10 点训练后冻结 | 2.587 ms | 4.900 ms | 5.141 ms |
| 10 点训练、每 1 s 更新 | 0.150 ms | 0.363 ms | 0.605 ms |

每侧 299 个相邻包间隔中各有 1 个相对 200 ms 名义周期偏差超过 1 ms；最大绝对偏差为 BLE 1.028 ms、IEEE 1.02825 ms，未见超过 5 ms 的间隔。这是时间轴诊断，不是独立 USB 零丢样证明。

这些结果来自真实解码包上的**离线掩码回放**：验证槽未参与训练，但失更由分析器模拟；误差是两侧反算共同计划时间参考的条件相对差，不是板端实际 RF 起点、绝对同步或物理执行时差。逐配置和逐验证槽结果见 [摘要 CSV](holdover.summary.csv)、[逐槽 CSV](holdover.validation.csv) 与 [结构化摘要](holdover.summary.json)。
