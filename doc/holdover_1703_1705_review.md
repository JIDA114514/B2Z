# 1703–1705 双接收端时间保持阶段复核

三轮均为同频诊断共包、受控馈线、两块独立 HackRF、4 Msps、200 ms 周期、预设 300 个槽。三轮板端逐槽日志均记录 300/300 个 secondary DMA 完成，且无 deadline miss / DMA timeout。两侧各自完成 PHY 和应用校验，并在每轮固定的 168 个验证槽都真实恢复了包；不同包训练与失更是**离线观察掩码**。1702 的 8 Msps 录制有采样时间轴跳变，只作故障诊断，不与这三轮合并。

| 指标 | 1703 | 1704 | 1705 |
|---|---:|---:|---:|
| BLE / IEEE 有效时间记录 | 300 / 300 | 300 / 300 | 300 / 300 |
| 同槽双方有效 | 300/300 | 300/300 | 300/300 |
| 板端 secondary DMA 完成 | 300/300 | 300/300 | 300/300 |
| 两侧最大相邻间隔偏差 | 0.918 / 0.918 ms | 0.9935 / 0.99375 ms | 1.028 / 1.02825 ms |
| 不同包、2 点训练并冻结：绝对相对差中位数 | 27.48 ms | 33.89 ms | 23.29 ms |
| 不同包、10 点训练并冻结：绝对相对差中位数 / P95 | 1.87 / 3.59 ms | 1.58 / 3.07 ms | 2.59 / 4.90 ms |
| 不同包、10 点训练、每 1 s 更新：中位数 / P95 | 0.133 / 0.392 ms | 0.138 / 0.376 ms | 0.150 / 0.363 ms |

三轮方向一致：在本组受控记录中，短跨度两点估频后长期失更会放大相对估计差；历史点增多或周期更新可降低误差。这是**三个独立物理录制轮次上的离线时间模型复核**，不是实际丢包后的在线成功率。1705 两侧各有一个相邻间隔相对名义周期偏差略超 1 ms，未见超过 5 ms 的间隔。三轮均无实测 RF 起点、共享采集触发或执行器动作。因此现有结果支持相对时间参考保持研究，不给出绝对时钟同步误差、同步执行精度或严格尾部误差界。
