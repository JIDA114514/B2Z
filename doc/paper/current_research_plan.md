# 当前论文主线与实验清单

更新：2026-11-20。[文档导航](../README.md)。本文件维护当前研究范围及优先级；历史总计划保留在 [archive](../archive/next_stage_plan.md)，旧待办不自动成为当前验收项。

## 已确定事项与本轮收敛

用户已接受 [UC1 修订方案](../reference/unified_compact_protocol_proposal.md)作为后续设计基准，包括独立 pending/closed 容量和 C3 成本重算。板端与主机代码已有 [P2 初验](../results/uc1_p2_2701_2718_review_20261120.md)；H4 四轮以板端日志和显式校正分析通过桥接初验，捕获 manifest 的溯源例外仍需披露。P2 结果可按此前提归档，进入 P3 前还需固定可追溯的代码/固件版本。后续改变字节布局、时间语义或基线成本时记录修订与证据影响。

本轮按用户“去除目前难以实现的目标”的方向，将默认主线收敛为：**单发送机下双协议共包的容量、成本与限定计划尝试的联合命令解析可靠性**。P2 的 2701–2718 均缺少可审计的独立 RF 参考界，截止期分类保留 `unknown`，当前不宣称严格截止期内交付。时间参考与失更管理作为支撑机制。最终题名、投稿对象、结果强度仍待证据确定，不将此次范围整理视作创新性或录用确认。

顺序：收敛必要主张与实验口径 → 完成相关软件并各做一次实测 → 冻结收发版本和统计口径 → 主要条件重复 → 冻结结果后撰写。当前不启动论文正文写作。

## 三层主张与完成证据

| 层次 | 要回答的问题 | 最小证据与结论边界 |
| --- | --- | --- |
| 共包承载 | 单 secondary 能否独立交付两侧完整命令与时间记录，布局如何限制应用容量？ | UC1 字节预算、生成边界、本侧独立校验与双端逐任务匹配。工作域与理论上限分开，不必先扩大到全部理论容量 |
| 成本—可靠性权衡（核心结果） | 负载和分片改变后，在同任务与同预算上限下，共包何时合算？ | K=1 成本交叉点、同预算上限重发、联合解析四分类及主要条件重复。允许 legacy 更省、无显著收益、特定条件失效 |
| 时间参考可用性（支撑） | 连续广播与单侧失更后，接收侧何时保持、拒绝和恢复使用参考？ | UC1 固定 secondary 下的时间更新/失更/重获桥接、留出预测残差与覆盖率。既不宣称绝对时钟精度，也不以拒绝行为证明同步执行收益 |

组合实现不是独立的新颖性证明。查新原报告的“足够发表、无需新实验”不采用，依据[审查意见](novelty_ab_claims_review_20261118.md)继续核对最接近工作。若差异仅是协议升级或字段压缩，应调整贡献定位，不能用增加无关实验掩盖。

## 移出当前验收的目标

| 原目标 | 当前处理 | 恢复条件 |
| --- | --- | --- |
| 实际同步执行、微秒级精度、组执行时差 | 不作为论文主张；保留软件事件与相对预测口径 | 可审计共同参考、误差预算及对应执行事件 |
| 最大持续任务速率、请求到物理动作时延 | 报告已测工作点、突发数量和成本；必要时记录同侧可审计处理跨度 | 定义可观测完成事件并另做速率扫描 |
| 跟随过程中的完整在线时间机制、严格 AuxPtr 时序合规 | 已有 N1 跟随作为分项功能证据；主要时间实验固定频点 | 单独立项并验证切频、采样连续性和时间参考 |
| 全距离/干扰/扫描窗口矩阵、独立多节点、商用兼容 | 只做与主张相关的有限 RF 条件；明确设备边界 | 具备设备与明确研究问题 |
| pure/exadv 极限吞吐、FreeRTOS 与裸机优劣 | 保留旧协议和可选支撑方案，不阻塞当前论文 | 用户明确开展相应性能研究 |

不再要求为 2204 拼补历史 IEEE 数据。若使用新格式声称跟随双端性能，应新建同轮实验；当前固定频点核心论文不以重做该轮为前置条件。历史 N1 的同期双端证据按原版本使用，不夸大为 UC1 已验证。

## 后续工作及完成条件

执行细节见 [UC1 论文主线实验计划](../plans/uc1_paper_experiment_plan.md)：软件优先、桥接初验、三负载/三封装成本与同预算矩阵、固定频点失更支撑。默认正式 81 个核心 run 加 9 个时间支撑 run，先导后冻结样本与时间判定口径；不代表现在可用旧命令启动。

| 顺序 | 工作 | 完成条件 |
| --- | --- | --- |
| 1 | 最接近前作全文对照 | 每条候选差异明确前作能力、本文约束、所需实验证据；未取得全文处保留未知 |
| 2 | UC1 共包与在线适配 | 明确版本分派、固定布局、纯时间更新、重发绝对截止期和数据稳定性；本地验证通过，保留历史格式回放 |
| 3 | 对照与预算工具 | exadv 分别发送及 legacy 对照使用相同任务语义；C3 独立队列/尝试身份、逐突发成本和时间可行性检查完成 |
| 4 | 新格式桥接实测 | 同 IQ 布局核验、独立双端命令/更新时间、K 重发、真实失更/恢复，各至少一次可复查记录；正式用到的 C3 同时初验 |
| 5 | 冻结确认性实验矩阵 | 明确应用长度、预算、周期、截止期、每轮任务数、RF 条件、顺序、计数与统计方法；不得依据结果挑选有利样本 |
| 6 | 主要条件重复与汇总 | 每主要条件至少 3 轮独立重复，交替顺序；输出失败、轮间变化、置信区间及适用边界。样本不足则增加样本或减弱结论 |

冻结矩阵至少覆盖直接 legacy 的短负载、需要分片的长负载、两侧负载分配有区别的代表点，以及至少一个实际存在解码缺失的受记录无线条件。具体数值和轮次数由先导结果估计，暂不生成占用 Run ID 的执行命令。均一 K 用于重发机制支撑；格式价值主要由同预算上限比较回答，避免两个实验无限扩张。

P2 [复核报告](../results/uc1_p2_2701_2718_review_20261120.md#p2-截止期方法审计)确认目前没有可信外部参考界。后续确认性结果限定为计划尝试内的联合解析与成本，逐任务截止期继续单列 `unknown`；不能把“计划在截止前发出”写为“截止前收到”。若恢复严格截止期主张，须先定义本侧包参考/观察窗口和不确定性，校准与留出验证分开；legacy 分片以最后一片完整记录可用时间审计，独立接收墙钟不能替代校准。

## 已有结果的用途

- [N4 两层结果](../results/n4_two_layer_results.md)：历史容量、分片与成本交叉点；C3 开销变化后必须重新计算及验证，不直接沿用 C2 成本。
- [N5 独立重复](../results/n5_independent_repeat_results.md)：固定频点真实失更/重获的机制基础；已记录人工时机偏差不作为全部重采理由。
- [均一 K 试采](../results/n5_uniform_k_pilot_results.md)：重发挽回任务的先导证据；各 K 一轮不能证明一般收益。
- [任务规则消融](../results/n5_task_rule_ablation_results.md)：回放及合成条件的软件证据，不替代真实同步执行。

历史数据按协议与配置单列，不与 UC1 拼成同条件重复；不因统一格式而全部废弃。新采集只补当前主张所需证据。
