# Run 1601：多任务共包功能评估

分析日期：2026-11-05。板端统计来自用户在对话中粘贴的 `CONTROL_PLAN_*` 行，已按原文保存为 [board.board.log](../../board.board.log)；它不是从串口终端直接导出的原始文件。逐时隙 [CSV](plan.slots.metrics.csv)、逐任务 [CSV](plan.tasks.metrics.csv) 和含来源哈希的 [JSON](plan.summary.json) 可复核下列计数。

## 结论

板端计划功能在这轮达到 DMA 层验收：9 个计划时隙全部生成，primary 和 secondary 均提交并轮询完成，`deadline_miss=0`、`dma_timeout=0`。BLE 独立接收链恢复全部 9 个控制时隙；IEEE 802.15.4 独立接收链只恢复时隙 1、3。**命令 43 双侧有效解析，命令 44 仅 BLE 侧有效解析；逐任务联合有效解析为 1/2。**因此本轮证明多任务字段和同一 secondary 共包的可解码性，但未达到两项任务均由两个独立接收端恢复的功能验收。

把 BLE 录制的**同一份 IQ** 交给 IEEE 802.15.4 解码器，完整回放可恢复 9/9 个控制时隙，且两侧同一时隙的共同字段均一致。这说明该 IQ 中的 BlueBee 区域可独立解码，不能代替两块 HackRF 的独立接收可靠性。

BLE 端 9 个包按计划出现 `ref_tick_ms=0,200,…,1600`；BLE 全部记录以及 IEEE 802.15.4 独立端实际恢复的记录均符合各自计划命令。BLE 严格 AuxPtr 匹配仍为 0，同频诊断配对为 9；不能据此宣称规范跨信道跟随。BLE 相邻恢复包间隔为 199.0345–200.3690 ms，仅用于观察本轮到包间隔，不是板端 RF 起点抖动的独立测量。

两端录制均正常结束并各处理 30 s IQ，接收队列未报告溢出。两端实际录制时间重叠，且 IEEE 802.15.4 端确实恢复了本轮时隙 1、3，因此少收不能归因于整个发送期未覆盖。相同 IEEE 802.15.4 解码参数和代码版本在独立 IQ 中恢复 2 包、在 BLE IQ 中恢复 9 包。再用 BLE 解码器读取 IEEE 802.15.4 那块 HackRF 的 IQ，只恢复板端的短 primary 时隙 **1、2、3、4、8（5/9）**，没有恢复 224 B 目标 secondary（0/9）；另有 329 个 CRC 有效 primary 不匹配板端帧特征。这些对照把差异定位到独立 ZigBee 录制的输入 IQ/接收条件，且长包比短 primary 更难恢复；现有证据仍不能区分天线/位置、无线干扰、前端设置或未显式可见的采样损失。此离线 BLE 解码不增加物理接收端数。

IEEE 802.15.4 解码器报告 3 个 FCS 失败**候选**；它们不能与 7 个未收到的计划时隙逐一对应，也不能直接计算空口误包率。

## 软件处理与时间边界

实时接收时两侧均未提供已校准的参考误差上界，因此定时任务被 `time_quality_insufficient` 拒绝是设计预期：BLE 对两条命令共 6 次候选均拒绝，IEEE 802.15.4 对收到的命令 43 候选拒绝，**没有实时软件处理事件**。

在明确标记为“未经校准的 1 ms 假设”的各自 IQ 离线回放中，BLE 对命令 43、44 各生成一次软件处理事件；IEEE 802.15.4 独立 IQ 只对恢复到的命令 43 生成一次。再用 BLE 的同一 IQ 完整回放 IEEE 802.15.4 侧时，命令 43、44 均各生成一次软件事件，最终软件状态为节点 2 的状态 1，并记录 `TRIGGER(7)`。这验证软件命令路径与去重，但不是两块独立设备的同步处理证据，更不是物理动作。

同一 IQ 内两种解码器给出的前导码标记差为 472.0–472.25 µs，与 472 µs 的设计布局一致；它只检验同一录制中的字段位置补偿。板端 `secondary_dma_late_us` 为最小 80,182、平均 80,542、最大 81,543 µs，参考的是**计划 secondary 起点到 DMA 提交函数返回**，不是实际空口起点。两台 HackRF 的采样零点、速率和固定接收延迟尚未校准，不能将两侧样本时间或软件事件直接相减报告同步误差。

## 判定与下一步

这轮可作为板端多任务调度、单 IQ 双协议共包解析及 BLE 独立接收的功能证据。独立双端的逐任务联合解析为 1/2，且只有一轮；不能用于稳定性、K 次重发收益或同步精度结论。下一步先检查 IEEE 802.15.4 独立接收链的 IQ/天线/增益条件，并用互换设备或位置的受控轮次定位差异；在射频条件稳定后再做至少三轮重复与 K 扫描。多任务板端日志的自动联合分析器仍待实现，本报告按逐时隙原始记录手工关联生成。
