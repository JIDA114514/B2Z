# 当前论文决策与实验清单

更新：2026-11-18。[文档总入口](../README.md)。本文件集中维护当前优先级；[原阶段总计划](../archive/next_stage_plan.md)保留技术任务与历史演进。

## 已确定的工作顺序

1. 确定最终论文目标、贡献范围和必要实验验收条件。
2. 完成涉及软件修改的必要功能，各至少获得一次可审计实验。
3. 冻结发送、接收版本和实验口径，再做参数化独立重复与鲁棒性验证。
4. 完成必要实验、冻结结果后开始论文撰写。

此前“已有组合足够发表一般 SCI、无需新实验”的判断不作为决策依据，原因见[查新审查](novelty_ab_claims_review_20261118.md)。目前未选定投稿对象，也没有对录用或收录作保证。

## 待确认的论文范围

候选研究问题：基于单个 BLE extended-advertising secondary PDU，向 BLE 与 IEEE 802.15.4 两侧传输各自控制及共同时间信息；在单发送机约束下，评价相对分别发送与 legacy 方案的容量、成本、联合解析可靠性以及失更后的时间参考可用性。这是建议范围，尚未由用户最终确认。

| 待决定事项 | 对实验和实现的影响 |
| --- | --- |
| 期刊完整研究论文或会议论文 | 决定目标范围与证据组织；录用标准须看具体投稿对象 |
| 最终采用 v1 还是 C1 统一方案 | C1 若作为在线时间机制的最终格式，需完成语义适配和桥接实测；现有 C1 解析不等于在线调度 |
| 固定 secondary 时间观察，或跟随模式在线时间机制 | 已有 N1 跟随与 N5 固定频点是分项证据；不能合称跟随模式下的完整在线机制 |
| 是否报告最大持续任务速率 | 纳入则需定义任务完成事件、扫描范围与持续可靠性；一个 500 ms 工作点不能称最大值 |
| 是否主张实际同步执行 | 现有证据不足；需共同参考、误差界与对应执行事件。增加重复不能替代测量方法 |

最终实验清单需在上述目标决定后冻结。本表不把所有候选扩展自动变成必做任务。当前不启动论文撰写，也不把新功能开发等同于研究贡献已成立。

## 已有结果的使用边界

- [N4 两层结果](../results/n4_two_layer_results.md)：收益随负载而变；波形预算不等于实测 RF 时长或能耗。
- [N5 独立重复](../results/n5_independent_repeat_results.md)：固定频点真实失更与重获的功能覆盖已完成，操作偏差保留。
- [N5 均一 K 试采](../results/n5_uniform_k_pilot_results.md)：重发挽回首发漏收已有实例；每 K 一轮不能确定一般增益。
- [任务规则回放](../results/n5_task_rule_ablation_results.md)：合成参考界、延迟注入和输入筛选均属于软件证据。
