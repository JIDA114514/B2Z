# Run 1704：独立双接收端时间保持复测

按[固定验证集方案](../../../../../doc/independent_sync_holdover_experiment_plan.md)分析两份独立 IQ。BLE 与 IEEE 802.15.4 接收器各自完成 PHY 和应用校验，分别恢复 300/300 个预设槽；同槽共享字段匹配 300/300。没有本轮板端最终统计，故这些数字是**相对预设槽位的有效解码覆盖**，不是与 `tx_completed` 相除的无线 PRR。详细逐槽结果见[匹配表](../control_match_1704/control.slots.metrics.csv)。

两份采集均完整处理 320,000,000 个 4 Msps 样本。299 个相邻包间隔中，两侧偏离计划间隔的最大绝对值分别为 0.9935 ms 和 0.99375 ms，均无超过 1 ms 的间隔；[时间线表](timing.qc.csv)没有 1702 轮的几十毫秒跳变。两侧接收队列高水位均为 2；BLE 削顶分量 194,728、IEEE 802.15.4 为 0。没有本轮配对的 USB shortfall 计数，不能据此证明完全无漏样。

与 1703 一样，初始训练槽为 0–19，验证槽固定为 `20≤s<300` 且 `s mod 5∈{2,3,4}`，共 168 个，均由两侧真实解码。`common` 使用相同偶数槽训练；`disjoint` 使用 BLE 偶数槽、IEEE 802.15.4 奇数槽。不同包训练与失更是**离线观察掩码**，不是真实 RF 漏收。下表为两侧各自反算的板端计划时间之相对估计差，单位 µs；全部 32 个方案见[汇总 CSV](holdover.summary.csv)、[逐槽 CSV](holdover.validation.csv)和[结构化 JSON](holdover.summary.json)。
