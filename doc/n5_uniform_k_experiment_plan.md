# N5 均一 K 物理对照实验计划

制定于 2026-11-17。承接 [N5 独立重复结果](n5_independent_repeat_results.md)、[任务规则消融](n5_task_rule_ablation_execution_plan.md)及 [N4 公平对照](n4_fair_comparison_plan.md)。2509–2517 已证明单侧失更与重获路径可跨轮观察；本计划不再要求补采这组机制实验。原轮的实际操作偏差保留在记录中，不用于剔除结果。

执行记录：2518–2520 实际分别采用 K=5/3/1，而非下文原定的三轮 K=5 条件搜索；其结果作为探索性首组试采，见[试采核查](n5_uniform_k_pilot_results.md)。本计划原有预登记内容保留，确认性轮次仍需在固定无线条件下交替重复。

## 1. 目标与可识别的结论

比较同一个 v1 共包任务在每轮统一重复 `K=1/3/5` 时的两侧及联合有效解析、首次成功尝试、截止前结果和成本。每个条件固定相同的六个命令、首次发送槽、目标、有效期、RF 参数、300 个计划槽、500 ms 周期及接收端在线时间模型。重发沿用同一 `run_id/command_id`，物理槽号另记；命令 0 是同步填充，不增加任务分母。

这里的公平性是**同一轮总波形预算上限**：增加命令重发时减少等长的同步填充槽。2509–2517 的逐突发记录中，每槽 primary 136 µs、secondary 1872 µs，总计 2008 µs；300 槽为 602400 µs，另有每槽 20 µs 零填充预算。新轮必须逐突发复核这些数，不能直接把历史长度当作新轮实测。K=1/3/5 分别包含 6/18/30 个命令尝试和 294/282/270 个同步填充槽；所有槽仍携带本侧时间参考。报告命令尝试成本、全部发送成本和单位成功任务成本，不把命令重发增加的成本隐藏在总预算不变之中。

此前馈线直连轮次均全收，因此直连仅用于命令、容量和成本的功能验收，**不作为 K 可靠性主对照条件**。用户已确认无线天线通信会出现随机丢包，因此正式 K 对照优先采用固定天线拓扑。原先约 25 s 的完整断连会吞没同一任务的全部 1–5 次尝试，不能识别 K 的可靠性收益。无线丢包不必独立同分布；正式比较须先观察任务突发内的部分成功、部分缺失，并在三组轮次间保持两侧天线、位置、功率和增益不变。若当前无线条件仍只有全收或整段全失，物理可靠性收益记为未测；离线擦除掩码单列为回放，不冒充 RF 实测。

## 2. 实现与采集门槛

1. `python/control_match/n5_config.py` 已增加 `--uniform-k 1|3|5` 和 `--board-commands` 导出入口；省略 K 时保留原混合 K 配置，不改旧文件。生成器按下表形成六任务，N5 探测槽、两侧训练候选、阈值和质量规则均保持不变。配置记录 K、任务表、条件说明、源码版本及哈希；板端固件/bitstream 标识仍须现场补记。生成、校验和命令槽位已有专项单测，正式采集前仍需用实际板端输出核对。
2. 板端现有 `b2z_plan_*` 接口即可执行；每组为 13 条表项，低于当前 16 条上限。裸机源码如需修改，仅作逻辑/语法检查，由用户编译上板。旧 v1 包、旧性能协议和 Sequence 语义不变。
3. 分析入口需按配置读取本轮任务尝试数，逐任务输出首次有效尝试编号、BLE/IEEE/联合解析、截止前解析、去重、拒绝原因，以及逐突发计划/提交/完成波形预算。比较脚本须核对三组首槽、命令语义、任务有效期、探测集、发送槽总数、波形长度和接收配置；不满足则拒绝标为公平对照。分析不可用“收到的前 K 包”补齐原计划缺失尝试。
4. 采集前冻结固件、bitstream、主机代码版本、接线/位置、功率、两块 HackRF 序列号和增益。不能以不同物理链路条件下的 1/3/5 直接推断 K 效果。

## 4. 物理条件与轮次

分两步试采，试采不能事后改成主实验重复：

1. 先用馈线直连做 K=1/3/5 的短功能核对，检查完整命令、六任务、300 槽、固定首槽、探测和逐突发成本。这一步只验证实现，不把全收结果算作 K 收益证据；按需使用新 Run ID，不占用正式对照编号。
2. 使用 2518–2520 做第一批**无线天线条件搜索**，每轮固定 K=5。每轮开始前设置候选距离、位置、朝向及既有 RF 增益/功率，整轮中保持天线和接收设置不动，不手工断连。两侧仍独立接收；检查各侧 300 槽有效率、六个任务各五次尝试的有效/缺失模式、最长连续缺失及主机接收质量。候选条件需在至少两次独立搜索轮次中出现任务突发内部分缺失，同时不能大面积连续全失；成功条件在主实验前冻结，K 三组都使用同一套两侧拓扑。若三轮仍不满足，用 2530 之后的新 ID 继续搜索，不动已预留主实验 ID。条件调节、失败点和实际天线布置均保存。不要用另一块正在接收的 HackRF 发干扰；人工拔馈线只适合完整断连边界，不作为 K 收益主条件。

达到可重复的部分缺失条件后，冻结它并开展三组各三轮，交替顺序以减小时间漂移：

| 顺序 | Run ID | K | 轮次 |
| ---: | ---: | ---: | ---: |
| 1–3 | 2521、2522、2523 | 1、3、5 | 第 1 轮 |
| 4–6 | 2524、2525、2526 | 5、1、3 | 第 2 轮 |
| 7–9 | 2527、2528、2529 | 3、5、1 | 第 3 轮 |

这些 ID 仅预留，执行前检查未占用。三组接收器均按 2509–2517 的两块独立 HackRF、BLE ch3/IEEE ch12、4 Msps、同一 N5 在线规则采集；增益、发射功率、接线/位置以搜索后冻结的配置为准，不能机械沿用直连时的 LNA16/VGA10。每轮采集 180 s，重新启动两侧进程与板端计划。至少每组一轮保存双侧完整 IQ，其余轮保存完整逐包、在线事件、接收摘要、板端原始日志及异常说明。若存储允许，优先保留出现部分缺失的关键轮双侧 IQ。每轮记录实际接线与设备状态；条件不稳的轮次保留并单列，不按结果好坏删除。

## 5. 分析与停止规则

每轮先核对配置/板端表一致、`reached/generated/primary_completed/tx_completed=300`、DMA 与 AuxPtr 计数、两侧 180 s/720M 样本、采集返回码、队列/USB 告警及源代码哈希。`tx_completed` 是 DMA 代理，无法唯一归因无线或接收损失；无告警不等于证明无丢样。用 `plan_analyze.py` 和 `n5_analyze.py` 的新分析目录生成逐槽四象限、探测/状态、逐任务结果及波形成本，固定留出探测不回填训练。

主要终点是**计划有效期前联合有效解析任务数/6**，另列至少一次联合解析、两侧各自解析、首次发送即联合成功、逐计划尝试位置的成功、未解析和异常数。联合按同一命令关联，分母按任务去重，不把两侧边际成功率相乘。区分“双方在某个同槽均有效”和“在同一任务的不同槽各自成功”。截止前口径依据各侧本地样本索引、已解码计划槽和预定周期作相对判定，并报告边界不确定的任务；它不是已校准的跨设备绝对截止判定。无校准共同参考时不得报告跨设备执行时差、同步执行成功率或真实动作成功。软件保守拒绝单列，不从解析率中隐去。

按轮报告全部相关 primary/secondary 的计划、提交和完成波形预算，包含命令 0、失败及重发；零填充、DMA 提交跨度另列，不叫实测 RF 占用。单位成功任务成本以提交波形预算除以联合解析数，零成功为 N/A。等总预算比较同时披露同步更新密度的变化，避免把 K 效应与时间模型输入变化混成纯无线分集效应。

每组三轮分别报告结果、均值、范围、按轮重采样的描述性 95% 区间；样本少且同轮任务/连续丢包相关，不把 18 个任务或所有包当独立样本。每轮同时报告命令 0 和固定探测槽的两侧有效率及最长缺失串，检查无线条件是否随 K 顺序漂移；不按观察到的高/低成功率事后删轮。只有在三组均有可审计的相近物理条件、任务突发内出现部分缺失、逐突发成本核对通过时，才作限定于该天线拓扑的物理 K 比较。如果全部任务总是全收，或中断总是覆盖整个突发，结论是**未辨识 K 的物理可靠性收益**，应先改进接收条件并以新 Run ID 预登记下一批；不能用离线筛选或假设干扰强度填出收益。
