# 单轮离线同步回放

Run 1201，Command 0；训练时隙 `<60`，验证时隙 `≥60`。
两侧独立用各自历史有效包拟合本地采样时间与包内计划时间的线性关系；1 包时只估计偏移，速率采用标称值。训练结束后冻结模型。
natural 使用各侧最近的包；disjoint 从 ZigBee 训练集中排除 BLE 训练时隙，模拟两侧收到完全不同的包。验证只使用更晚的共同有效包。
