# Run 10269：700 kHz 实时重测未改善

日期：2026-10-27。本轮确认：参数实际生效，但没有得到可重复的实时改善。上轮 700 kHz 对旧 IQ 的离线改善可复现，不能视为双设备接收问题已经稳定解决。

## 配置与采集

ZigBee 输入为 `python/zigbee_rx/results/rx_20261027_161603_006777.ci8`，设备末尾 3348a6c3；BLE 输入为 `python/exadv_rx/results/rx_20261027_161604_978887.ci8`，设备末尾 2926a0c3。两份都是 40 s、8 Msps、640 MB，采集 complete、退出码 0。

ZigBee 已实际使用 `cutoff_hz=700000`、`dc_block_hz=1000`、`phase/project`、Run ID 10269、payload 30 B。原实时链确实恢复 0 包，只有 1 个前导码候选且被拒；不存在被 Run ID 筛掉的有效帧。

两侧应用队列最高分别为 12/64（ZigBee）和 10/64（BLE），没有报告溢出。源码散列与上一轮成功恢复 68 包的 700 kHz 离线回放相同，不能将本轮失败归因于时间戳显示修改或参数未应用。

新 BLE 设备实时显示 629 包，其中 626 为 primary、只有 3 个为有效目标 secondary，Sequence 为 76、88、92，均为 Run 10269、30 B。不能把 629 当作目标测试成功包数。

将新 ZigBee 设备 IQ 交给 BLE 解码器，能恢复 640 个环境 primary，但目标 secondary 为 0，且旧目标 primary PDU 模式 `07074618c80d03e823` 也为 0；BLE 设备 IQ 中该目标 primary 模式有 59 个。当前故障范围因此偏向 3348a6c3 这条路径对目标信号的接收质量/采集条件，而不是所有 RF 信号都不能接收。

这里的“未恢复目标”不代表目标在该天线处物理上完全不存在，可能只是低于解码条件。现有数据不足以确定天线接触、空间衰落、供电/USB、RF 耦合或具体干扰源；不能据此直接宣判设备损坏或两台 HackRF 必然互扰。

## USB 与硬件计数

事后只读查询设备 3348a6c3 的 `hackrf_debug --state`：IDLE、shortfalls=0、longest shortfall=0、Error=NONE，M0/M4 计数约 640 MB。没有发现该设备报告的 RX shortfall。该查询不是连续监测，计数属于最后状态，不能作为所有路径绝对无丢样的证明。

2926a0c3 查询返回 `feature not supported by installed firmware (-1005)`，该设备无法用此命令补充硬件计数；本次没有修改其固件。

sysfs 显示两台设备连接于同一个 USB2 hub：3348a6c3 在 `1-3.2.3`，2926a0c3 在 `1-3.2.1`。这是后续控制实验应记录的条件，单凭共享 hub 不能确定带宽不足。原始拓扑见 `usb_tree.summary.txt` 和 `usb_topology.summary.json`。

## 下一步：单台—双台—单台

不再以当前数据为理由继续盲扫截止频率。已准备 `python/sync_validation/capture_single_dual.py`，在固定天线、设备位置、USB 线和发送配置下，仅改变接收进程活动状态：

1. 3348a6c3 单独接收 30 s。
2. 两台同时接收 30 s。
3. 3348a6c3 再单独接收 30 s。

用户先启动持续发送 `bluebee_exadv_perf_start?30 200000 0 10270`，再运行脚本；结束后手动 `bluebee_perf_stop?`。不需要手动重启接收进程，脚本保存四份独立 IQ、阶段配置、设备日志和逐包结果，总 IQ 约 1.92 GB。真实 A/B 实验尚未执行；工具仅完成 dry-run 和无硬件回归。

若两次单台都能恢复，而中间双台显著下降，支持双设备活动相关问题，需重复并进一步区分 USB/供电和 RF 耦合。若单台也持续为 0，优先检查目标信号路径，并通过交换天线/线缆或 USB 路径、一次只改变一项来定位是否随设备或附件迁移。没有这种控制证据前，不直接归因于“同时启动”。

连续发送的 Sequence 跨阶段递增，脚本不设置从零开始的 expected-packets，也不据 30 s 自动推算无线 PRR。当前两路独立时间轴尚未校准，没有计算同步精度。
